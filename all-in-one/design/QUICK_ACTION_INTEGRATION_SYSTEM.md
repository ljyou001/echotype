# 快速操作整合系统设计文档

## 1. 概述

### 1.1 功能描述
快速操作整合系统是一个插件化的文本分发系统，允许用户在语音识别完成后，通过特定的热键操作触发一个精简的弹窗，快速将识别的文本发送到各种外部服务（搜索引擎、AI助手、翻译服务等）。

### 1.2 核心特性
- **智能热键触发**：根据热键按压时长判断用户意图（录音 vs 快速操作）
- **文本记忆**：自动保存上一次语音识别的文本内容
- **插件化架构**：支持动态添加和配置各种整合服务
- **多实例支持**：同一插件类型可创建多个实例，配置不同参数和自定义名称
- **拖拽排序**：用户可自定义整合按钮的显示顺序
- **精简UI**：快速操作窗口仅显示图标，鼠标悬停显示名称
- **一键发送**：点击图标或按回车键快速发送到目标服务

### 1.3 用户场景示例

**场景1：快速搜索**
1. 用户说："今天天气怎么样"
2. 语音识别完成后，用户轻点热键（<0.1秒）
3. 弹出快速操作窗口，显示识别的文本和图标按钮
4. 用户点击 🔍 图标
5. 系统打开浏览器，在Google搜索"今天天气怎么样"

**场景2：发送到AI助手**
1. 用户说："帮我写一封邮件"
2. 轻点热键触发快速操作窗口
3. 用户点击 🤖 图标（工作用ChatGPT）
4. 文本被发送到ChatGPT API，返回结果显示在通知中

**场景3：使用默认服务**
1. 用户说："translate this to Chinese"
2. 轻点热键触发快速操作窗口
3. 用户直接按 Enter 键
4. 文本被发送到默认服务（Google搜索）

### 1.4 语言支持
- **默认UI语言**：英文
- **支持语言**：英文、中文
- 所有UI文本使用i18n国际化

### 2.2 核心模块说明

#### 2.2.1 热键时长检测模块
**功能**：
- 记录热键按下和释放的时间戳
- 计算按键持续时长
- 根据录音模式和时长触发不同行为

**触发规则**：
- **Push-to-Talk 模式**：
  - 轻点（<100ms）→ 触发快速操作窗口
  - 正常按住（≥100ms）→ 正常录音
  
- **Toggle 模式**：
  - 长按（≥500ms且未释放）→ 触发快速操作窗口
  - 正常点击（<500ms）→ 切换录音状态

**实现位置**：`frontend/electron/hotkey-manager.ts`

#### 2.2.2 快速操作窗口管理器
**功能**：
- 创建和管理快速操作窗口
- 窗口特性：小型、无边框、置顶、透明背景
- 窗口定位：鼠标位置附近或屏幕中心
- 失焦自动关闭

**窗口规格**：
- 宽度：450px
- 高度：200px（根据内容动态调整）
- 样式：圆角、阴影、模糊背景

**实现位置**：`frontend/electron/quick-action-window.ts`（新建）

#### 2.2.3 整合插件系统
**核心概念**：
- **插件（Plugin）**：插件类型定义，如"ChatGPT"、"Google搜索"
- **实例（Instance）**：插件的具体配置实例，如"工作用ChatGPT"、"个人ChatGPT"

**插件接口**：
每个插件需要实现：
- `execute(text, config)`：执行整合操作
- `validateConfig(config)`：验证配置是否有效
- `getConfigSchema()`：返回配置表单定义
- `getDefaultName()`：返回默认实例名称

**实例数据结构**：
- `instanceId`：唯一标识符（UUID）
- `pluginId`：插件类型ID
- `name`：自定义显示名称
- `icon`：图标（emoji）
- `order`：显示顺序（影响快速操作窗口中的按钮顺序）
- `enabled`：是否启用
- `isDefault`：是否为默认服务
- `config`：实例特定配置（API Key、端点等）

**实现位置**：`frontend/src/services/integrations/`

## 4. UI 设计

### 4.1 快速操作弹窗

**设计原则**：
- 极简主义：只显示必要信息
- 图标优先：减少文字干扰
- 快速响应：支持键盘快捷操作
- 视觉清晰：使用对比色突出默认服务

**布局结构**：
```
┌───────────────────────────────────────┐
│  Quick Action                    [×]  │  ← 标题栏
├───────────────────────────────────────┤
│                                       │
│  📝 Last transcribed text:            │  ← 文本标签
│  ┌─────────────────────────────────┐ │
│  │ This is the last transcribed... │ │  ← 文本预览（可滚动）
│  └─────────────────────────────────┘ │
│                                       │
│  🔍  🤖  🌐  🔎  🦾  💬             │  ← 图标按钮（单行）
│                                       │
│  Press Enter for default (🔍)        │  ← 提示文字
└───────────────────────────────────────┘
```

**交互细节**：
- **图标按钮**：
  - 尺寸：48x48px
  - 间距：8px
  - 默认服务：边框高亮显示
  - 鼠标悬停：显示tooltip、轻微上移动画
  
- **Tooltip**：
  - 位置：图标上方
  - 内容：实例名称（如"Work ChatGPT"）
  - 样式：深色背景、白色文字、圆角

- **键盘操作**：
  - Enter：使用默认服务
  - Escape：关闭窗口
  - 点击窗口外：关闭窗口

**尺寸规格**：
- 窗口宽度：450px
- 窗口高度：约200px（根据内容动态调整）
- 文本预览区：最大高度80px，超出滚动

### 5.2 安全考虑

**API Key 加密**：
- 使用 Electron 的 `safeStorage` API 加密存储敏感信息
- 配置文件中的 `apiKey` 字段存储加密后的值
- 读取时自动解密

**配置文件权限**：
- 仅当前用户可读写
- 不在日志中输出敏感信息
